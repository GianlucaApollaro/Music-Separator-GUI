1. Installation

Windows (CPU or GPU)

If you downloaded the standalone precompiled version:

  1. Download the archive format .7z suitable for your machine (GPU version for NVIDIA CUDA graphics cards, or CPU version for other cards or processors).
  2. Extract the archive using a tool like 7-Zip.
  3. Launch the application directly by clicking on Music separator.exe (GPU) or Music separator CPU.exe (CPU).

If you are installing from source code:

  • Run install.bat (or install_cpu.bat) to create the Python virtual environment and download dependencies.
  • Run run.bat (or run_Cpu.bat) to launch the program.

macOS (Apple Silicon M1/M2/M3/M4)

  1. Download the Mac package in .zip format.
  2. Extract the archive and move the resulting folder to your /Applications folder (e.g. /Applications/Music Separator/).
  3. Right-click on the application and select Open (only required for the first launch to bypass Apple Gatekeeper's security checks).

Note: FFmpeg is included in the package. If you encounter permission blocks, open your Terminal and run:

xattr -cr "/Applications/Music separator.app"

3. Basic Usage (Single Model)

To start a classic separation with a single model:

  1. Drag and drop or browse your input file in the Input Audio File field.
  2. Select an Output Directory.
  3. Click on the Model field to select a model.
    • On Windows and Linux, models are organized in a categorized tree with a search bar.
    • On macOS, models are listed in a simplified, native, accessible listbox.
    • Locally downloaded models appear in the special category "Downloaded Models (Offline)" at the top of the list.
  4. Select the output format (WAV, FLAC, or MP3) and the target quality/resolution:
    • WAV: 16-bit, 24-bit, or 32-bit Float (studio quality).
    • FLAC: 16-bit or 24-bit (high-resolution lossless).
    • MP3: 320 kbps, 256 kbps, 192 kbps, or 128 kbps.
  5. Click on Start Separation.

4. Native Ensemble (Mixing Two Models)

Check the Enable Ensemble box to combine the outputs of two different models:

  • Choose the primary model (Model 1) and the secondary model (Model 2).
  • Choose the Ensemble Algorithm to blend the waveforms (e.g. avg_wave to average the tracks, min_wave, max_wave, or median_wave).
  • Recommended: The default avg_wave option generally produces the cleanest and most natural stems.

5. Chained Presets & Custom Presets (Advanced)

The Preset dropdown allows you to run complex multi-model processes where the output of one separation is automatically fed into another model for further cleaning or stem split.

Creating Custom Presets

You can create and manage your own custom presets directly from the GUI:

  • Click the Create Preset button next to the Preset dropdown to open the Creator Dialog.
  • Enter a Name and choose the type (Single Model or Chained Models).
  • Single Model: Select the model, define suffix mappings for output files, and optionally enable "Mix Remaining" to combine all other stems.
  • Chained Models: Add consecutive steps, choose a model for each step, select which stem to pass to the next step, and use the checklist grid to choose which other stems to keep and their custom suffixes.
  • Click Save Preset. The preset will immediately appear in the dropdown.
  • To delete a custom preset, select it from the dropdown and click the X button.

Importing & Exporting Presets

  • Exporting: Click the Export Presets button or go to File → Export Presets... to save all custom presets to a portable JSON file.
  • Importing: Click Import Presets or go to File → Import Presets... to import presets from other machines or backups.
  • From Command Line (CLI): Use --export-presets [file.json] and --import-presets <file.json>.

Built-in Chained Presets

  • Vocal Split: Separates instrumental and vocals, then splits the vocal track into Lead vocals and Backing vocals.
  • Vocal De-Reverb: Extracts vocals and automatically removes background reverb and echo.
  • Ultimate Stems (7 Tracks): Extracts vocals and instrumental, then splits the instrumental track into 5 stems (Bass, Drums, Piano, Guitar, Other) and saves an extra _Extra file.
  • Ultimate Stems + Drum Split: Powered by the 5-pass engine, it extracts full Instrumental (_Instrumental with strings included), isolates Bowed Strings (_Strings), Lead vocals, Backing vocals, Bass, Piano, Guitar, Other instruments, and splits the drums into individual components (Kick, Snare, Cymbals, Toms, etc., for a total of 15 isolated tracks).
  • Guitar Extraction: Preset optimized to isolate lead/rhythm guitars from the rest of the song.
  • Male/Female Split: Splits the vocal track specifically isolating male vs. female voices.
  • Live Restore: Isolates and extracts crowd noise or applause, then divides the music performance into backing and clean vocals.
  • RVC Vocal Prep: Isolates an exceptionally clean Lead vocal track to be used as an RVC training dataset.
  • Only Drums: Extracts the drum kit, removing all melodic or vocal elements.
  • Only Drums + Backing: Extracts the drum kit (_Drums) and merges all vocals, bass, guitar, piano, and other instruments into a single backing track (_No_Drums).

6. Output Options & Cleanup

  • Save in subfolder: If checked, automatically creates a subfolder named after the input song. Recommended for keeping chained/multi-stem outputs organized.
  • Delete silent stems: If enabled, automatically deletes generated stems that are quieter than the configured threshold (-20 dB to -80 dB in 5 dB steps; default: -50 dB).
  • Play Stem: Click this button after separation completes to open a dialog and quickly play any generated stem in your system's default media player.

7. Chunking (Out-of-Memory Prevention)

If you experience application crashes due to full VRAM (graphics card memory) or if you process very long files (e.g. DJ sets):

  • Check Enable Chunking.
  • Select a duration in minutes (e.g. 2 or 5 minutes). The audio will be split into temporary segments, processed in blocks, and seamlessly merged back together.

8. Batch Processing (Multi-file and Folders)

You can load and process multiple files at the same time:

  • Use the Browse button and select multiple files in the dialog to queue them.
  • Click on Browse Folder to load all supported audio files within a directory (and its subdirectories).
  • The interface will display both the overall progress and the current song progress in real time.

9. Technical Notes & Suffixes

Output files will contain specific suffixes indicating the isolated stem:

  • _Vocals: Combined vocal track.
  • _Instrumental: Complete backing track.
  • _Lead: Main lead voice.
  • _Backing: Backing vocals and choruses.
  • _DeReverb: Dry voice without reverb.
  • _Drums: Drum kit.
  • _No_Drums: Complete backing track excluding the drums.
  • _Bass: Bass guitar / synth bass.
  • _Guitar: Guitar tracks.
  • _Piano: Acoustic / electric piano.
  • _Other / _Extra: Synthesizers or uncatalogued elements.

10. Command-Line Interface (CLI / Headless Mode) v1.7

Starting with version 1.7, Music Separator includes a full-featured command-line interface to automate separations without opening the graphical user interface.

Key Arguments

  • -i, --input <files...>: Audio file(s), folder, or glob pattern (e.g. *.wav).
  • -o, --output-dir <dir>: Destination folder (default: ./output).
  • -m, --model <name>: Model friendly name, alias, or substring (does not require .ckpt or .onnx extensions, e.g. "Viperx-1297" or "Inst_HQ_5").
  • -p, --preset <name>: Built-in or custom preset name (e.g. preset_vocal_split or "Denoise + Vocals").
  • -r, --recursive: Recursively scan subfolders when input is a directory.
  • --format {WAV,FLAC,MP3}: Output format (default: WAV).
  • --bit-depth {16,24,32}: Bit depth for WAV (16, 24, 32 Float) and FLAC (16, 24).
  • --bitrate {320k,256k,192k}: Bitrate for MP3 format (default: 320k).
  • --gpu / --cpu: Force GPU acceleration (CUDA/MPS) or CPU execution.
  • --no-subfolder: Save stems directly in output folder without per-song subdirectories.
  • --clean-names: Strip leading track numbers from folder names.
  • --delete-silent-stems: Automatically remove generated stems that contain only silence.
  • --silent-stem-threshold <dB>: Threshold in dB below which a stem is considered silence (default: -50 dB).
  • --chunk-duration <sec>: Process audio in chunks of N seconds.
  • -l, --list-models: List all catalog models and their download status.
  • --list-presets: List all built-in and custom presets.
  • --download-model <name>: Download a model to the local catalog and exit.

Windows Examples

# Separation using a model
"Music separator.exe" -i song.wav -m "BS-Roformer-SW.ckpt" -o "./output"

# Separation using a preset
"Music separator.exe" -i song.wav --preset "preset_vocal_split"

# Entire folder in recursive mode
"Music separator.exe" -i "D:\Music\Album" -r --preset "preset_vocal_split"

# Catalog inspection
"Music separator.exe" --list-models
"Music separator.exe" --list-presets

macOS Examples (Terminal)

# Direct execution from .app bundle
"/Applications/Music Separator/Music separator.app/Contents/MacOS/Music separator" -i song.wav -m "BS-Roformer-SW.ckpt"

# Fast alias in ~/.zshrc
alias music-separator='"/Applications/Music Separator/Music separator.app/Contents/MacOS/Music separator"'
music-separator -i song.wav --preset "preset_vocal_split"
